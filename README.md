# Radio Player Denmark
website live here: https://voldedev.github.io/radio/

## Opdateringsbesked

Siden kontrollerer `version.json` hvert minut. Når versionen ændres efter en GitHub Pages-deploy, får besøgende en popup med en knap til at genindlæse siden. Ved fremtidige udgivelser skal værdien i `version.json` og meta-tagget `app-version` i `index.html` opdateres sammen.
